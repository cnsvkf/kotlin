## 개념

- Kotlin이 is로 타입을 확인한 뒤, 그 범위 안에서는 __자동으로 타입을 바꿔서 사용할 수 있게 해주는 기능__

    - 개발자가 직접 as로 다운캐스팅 하지 않아도, Kotlin이 처리

| 개념         | 의미                            |
| ---------- | ----------------------------- |
| `is`       | 특정 타입인지 검사                    |
| 스마트 캐스트    | `is`로 확인한 뒤 자동으로 그 타입처럼 사용 가능 |
| `as`       | 직접 강제 타입 변환                   |
| `as?`      | 실패하면 `null`을 주는 안전한 타입 변환     |
| 스마트 캐스트 장점 | 직접 캐스팅보다 안전하고 코드가 짧음          |



## 예시 

```Kotlin
open class Animal {
    fun breathe() {
        println("숨 쉰다")
    }
}

class Dog : Animal() {
    fun bark() {
        println("멍멍")
    }
}

fun main() {
    val animal: Animal = Dog()

    if (animal is Dog) {
        // 여기 안에서는 Kotlin이 animal을 Dog 타입으로 자동 인식한다.
        animal.bark()
    }
}

// animal.bark() // 원래는 불가능 헀지만 if 문 안에서 가능하게 해줌
```

-> 중요 부분

```kotlin
if (animal is Dog) {
    animal.bark()
}
```

## 기존 방식(as)과의 비교

1. 기존 방식

```kotlin
val animal: Animal = Dog()

val dog: Dog = animal as Dog

dog.bark()
```

: animal을 Dog로 바꿔서 dog 변수에 넣기

2. 스마트 캐스트 

```kotlin
val animal: Animal = Dog()

if (animal is Dog) {
    animal.bark()
}
```

: animal이 Dog인지 확인했으니까, 이 안에서는 Dog로 취급

## 스마트 캐스트가 안전한 이유

- as 방식은 실패 시 앱이 터짐

    - 스마트 캐스트는 검사 후 사용해 안전
