## 개념

- __자식 타입을 부모타입으로 전환__

- as 안써도 됨



-> 예시 

```kotlin
open class Animal {
    fun breathe() {
        println("숨 쉰다")
    }
}

class Dog : Animal() {
    fun bark() {
        println("멍멍")
    }
}

class Cat : Animal() {
    fun meow() {
        println("야옹")
    }
}
/*
Animal
 ├─ Dog
 └─ Cat
 */

// Cat 객체를 만들었다.
// 그런데 변수 타입은 Animal로 받았다.
val animal: Animal = Cat()
```

: 되는 이유 - 업캐스팅




### 업캐스팅은 자동으로 된다. (as X)

- _____Cat()은 Cat 클래스의 객체지만, Animal을 상속받았기에 사용 가능_____

## 쓰는 이유

- 여러 자식 타입을 하나의 부모 타입으로 묶기 위해서

```kotlin
open class Animal {

    // 모든 동물이 공통으로 실행할 기능
    open fun makeSound() {
        println("동물이 소리를 냅니다")
    }
}

class Dog : Animal() {

    // Dog의 소리 기능
    override fun makeSound() {
        println("멍멍")
    }
}

class Cat : Animal() {

    // Cat의 소리 기능
    override fun makeSound() {
        println("야옹")
    }
}

class Bird : Animal() {

    // Bird의 소리 기능
    override fun makeSound() {
        println("짹짹")
    }
}
```
각 각 다른 타입이지만 Animal로 묶을 수 있음 
: 업캐스팅

```Kotlin
val animals: List<Animal> = listOf(
    Dog(),
    Cat(),
    Bird()
)

animals.forEach { animal ->
    animal.makeSound()
}
```
    Dog → Animal
    Cat → Animal
    Bird → Animal
