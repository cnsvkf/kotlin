## 개념

- _____부모타입을 자식 타입으로 변환_____

쓰는 이유 :
- __이미 어떤 객체가 있는데, 그 객체가 지금은 부모타입으로 보이고 있을 때, 다시 자식 타입으로 사용하려고 쓰는 것__

-> 예시

```kotlin
open class Animal {
    // 모든 동물이 공통으로 가지는 기능
    fun breathe() {
        println("숨 쉰다")
    }
}

class Dog : Animal() {
    // Dog만 가지는 기능
    fun bark() {
        println("멍멍")
    }
}

fun main() {
    // Dog 객체를 새로 만든다.
    // 단, 변수 타입은 Animal로 받는다.
    val animal: Animal = Dog()


    // animal이 가리키는 실제 객체가 Dog인지 확인한다.
    // 실제 Dog가 맞으면 같은 객체를 Dog 타입 변수 dog로 참조한다.
    val dog: Dog = animal as Dog

    // dog는 Dog 타입이므로 Dog 전용 메소드를 사용할 수 있다.
    dog.bark()
}
```
-> animal.bark() 안되는 이유 : 변수 타입이 Animal 이기 때문이다.

```kotlin
val animal: Animal = Dog()

animal.breathe() // 가능
animal.bark()    // 불가능
```

\+ dog.bark()가 가능한 이유 

1. animal이 가리키던 기존 Dog 객체를 Dog 타입 변수 dog가 다시 가리키게 하는 것이다.

2. __객체를 변경하는 게 아니라, 자식이 보는 타입을 Animal에서 Dog__ 로 바꾸는 것이다.
