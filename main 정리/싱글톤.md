# 개념

### 싱글톤 = objdect

- 예시

```kotlin
object UserManager {
    var name: String = "지성"

    // 현재 저장된 이름을 출력하는 메소드
    fun printName() {
        println(name)
    }
}
```

-> 사용

    UserManager.name = "박지성"
    UserManager.printName()

---
- companion object : 객체 생성 없이 클래스 이름으로 접근 가능한 영역
    - 형식
```kotlin
class MathUtil {
    companion object {
        fun sum(a: Int, b: Int): Int {
            return a + b
        }
    }
}
fun main() {
    println(MathUtil.sum(3, 4))
} // 7
```
---
### Kotlin에서 object는 “클래스”도 아니고 “속성”도 아님.
    정확히 말하면:
    object는 객체를 딱 1개만 만드는 Kotlin 문법이다.
    즉, 싱글톤 객체를 선언하는 키워드에 가깝다.
